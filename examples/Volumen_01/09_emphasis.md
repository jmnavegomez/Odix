# Emphasis and text formatting

Odix provides several ways to emphasise and format text inside a Principium.

## Italic text

Text can be written in italics using middle points:

```text
·this text is italic·
```

## Bold text

Bold text can be written using asterisks:

```text
**this text is bold**
```

## Underlined text

Text can be underlined using repeated underscores:

```text
___this text is underlined___
```

## Inline code

Short pieces of source code can be included directly in a paragraph using backticks:

```text
The `print()` function writes a value to the standard output.
```

## Combining emphasis

Different forms of emphasis can be used to distinguish important elements within technical text.

For example:

```text
The **important** parameter is **·optional·**, while `None` represents the absence of a value.
```

## Summary

Text formatting can be used to improve the readability of a Principium without changing its structure.

The main inline formatting elements are:

+ italic text;
+ bold text;
+ underlined text;
+ inline code.

These elements are converted by Odix into the corresponding publication markup.
